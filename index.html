La demo web non c'è più. DoubleScreener v2 è un'applicazione locale: la regia gira sul tuo computer e il browser serve solo come secondo schermo.

Il progetto

Una regia, nessun cloud.

DoubleScreener nasce per proiettare contenuti su un secondo schermo senza passare da servizi online. Tutto ciò che serve — progetti, immagini, pagine PDF — resta sul computer che apre la presentazione.

Locale per scelta

Niente database, login o sincronizzazione remota: i progetti sono file JSON sul disco e il server ascolta solo sulla rete locale.

Un solo renderer

Canvas, player ed export condividono lo stesso codice di rendering: quello che vedi in regia è esattamente ciò che arriva sullo schermo.

Aperto e tradotto

Codice GPL-3.0, documentazione tecnica inclusa e interfaccia in italiano e inglese. Nessun componente proprietario.

Funzionalità

Tutto quello che serve per proiettare.

Editor, PDF, secondo schermo ed export in un'unica applicazione.

Regia desktop nativa

Costruita con PyQt6: pannelli progetti e slide, ispettore, palette e canvas HTML5. Niente schede del browser da tenere aperte.

Slide HTML e PDF

Crea slide da zero o importa pagine da un PDF a intervalli. Le pagine vengono renderizzate lato server in immagini leggere, pronte per il player.

Editing visuale

Trascina, ridimensiona e ruota gli elementi con snap e guide. Zoom 25–200%, testo modificabile inline, annulla/ripristina e salvataggio automatico.

Inspector completo

Geometria, rotazione, opacità e livello; tipografia, colori e allineamento; sfondo, bordo, raggio, ombra e animazioni d'ingresso.

Template e temi

Cinque layout pronti — titolo, sottotitolo, elenco, immagine a tutto schermo, due colonne — e quattro temi colore applicabili al progetto.

Second screen, zero app

TV, tablet o un altro PC aprono il player nel browser. Un QR code li collega; ogni schermo mostra la stessa slide, e con un tasto va in nero.

Export autonomo

Esporta il deck come cartella statica o come singolo file HTML con asset inclusi: si apre da file:// anche su un computer senza DoubleScreener.

Il tuo spazio locale

Progetti in JSON, asset in una cartella dedicata, nessun tracciamento. Interfaccia e player disponibili in italiano e inglese.

Installa

Da sorgente, in pochi minuti.

DoubleScreener v2 è in sviluppo attivo: per ora si installa da sorgente. Servono Python 3.11+ e Git.

Requisiti

  • Python 3.11+ — testato su Python 3.13.
  • Windows, Linux o macOS — su Linux servono le librerie Qt/WebEngine della distribuzione.
  • Nessun Node.js — il frontend è già incluso nel pacchetto.

Il codice della v2 è su main. Il progetto è ancora in sviluppo: non ci sono release pacchettizzate.

Terminal 
git clone https://github.com/il-mangia/doublescreener.github.io.git
cd doublescreener.github.io

python -m venv .venv

# Windows
.\.venv\Scripts\Activate.ps1

# Linux / macOS
source .venv/bin/activate

pip install -e ".[gui]"
python -m doublescreener

Poi…

Con la regia aperta, il pannello Presentazione mostra l'indirizzo per il secondo schermo (ad esempio http://192.168.1.20:8765/p) e il QR code. I dati vengono salvati nella cartella utente dell'app; usa --data-dir per sceglierne un'altra.
